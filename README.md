# K Manimaran — Developer Portfolio

A performance-focused personal portfolio built to showcase production-ready full-stack applications, interactive UI components, and real-world MERN systems.

## 🚀 About the Portfolio
This project acts as the central hub for my technical work, featuring detailed case studies, live previews, and architecture breakdowns for apps built from database schema to deployment.

## 🛠️ Tech Stack
* **Frontend:** React, HTML5, CSS3, JavaScript (ES6+)
* **Effects & Animation:** Custom WebGL, GSAP, ScrollTrigger, Lenis
* **Hosting:** GitHub Pages
